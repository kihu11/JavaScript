1.Что из себя представляет localStorage?:
Встроенное в браузер хранилище пар «ключ-значение» (Web Storage API). 
Данные сохраняются бессрочно — до явного удаления кодом или пользователем. Привязано к origin (протокол + домен + порт). Объём ~5–10 МБ. API синхронное.


2.Что из себя представляет sessionStorage?

То же самое по API и объёму, но данные живут только в рамках текущей сессии вкладки. 
Закрыл вкладку — данные исчезли. Каждая вкладка имеет свой отдельный sessionStorage, даже если это один и тот же сайт. 
Перезагрузка страницы данные сохраняет.


3.Когда использовать localStorage

    Настройки интерфейса: тема, язык, размер шрифта, свёрнутые панели.

    Данные, которые должны пережить закрытие браузера: черновики, корзина, «недавно просмотренные».

    Кэш редко меняющихся данных, чтобы не дёргать сервер.

    Флаги авторизации и токены — с оговоркой: уязвимо к XSS, для чувствительных данных лучше httpOnly cookie.


4.Когда использовать sessionStorage

    Состояние формы или пошагового визарда в рамках одной сессии.

    Временные фильтры, сортировки, промежуточные данные навигации.

    Данные, которые должны быть изолированы между вкладками (чтобы две вкладки не конфликтовали).

    Одноразовые вещи: токен для OAuth-редиректа, идентификатор сессии на время работ

5.Разница между localStorage и sessionStorage
Критерий	localStorage	     sessionStorage
Время       жизни бессрочно	     до закрытия вкладки
Область     видимости	         все вкладки одного origin	только текущая вкладка
Событие     storage	срабатывает в других вкладках	только в текущей
Объём	    ~5–10 МБ        	~5–10 МБ
API	        идентичный	        идентичный
